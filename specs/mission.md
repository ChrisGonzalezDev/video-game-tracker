# Mission

## Application

**Name:** Video Game Inventory Tracker

**Description:** A full-stack web application for managing, searching, and exploring a personal video game collection. It also demonstrates end-to-end software engineering practices across a modern TypeScript and Java stack.

## Mission

Give an individual video game collector a centralized place to catalog their collection, record useful game details, and quickly find games through search and filtering. Deliver the experience as a credible portfolio project that demonstrates modern frontend development, backend API design, relational data modeling, automated testing, and containerized local execution.

## Intended users

- **Primary user:** An individual managing a personal video game collection.
- **Secondary audience:** Portfolio viewers evaluating the project's user experience, architecture, and engineering practices.

## Goals

- Support adding, viewing, editing, and deleting games and their collection details.
- Make the collection easy to explore through title or keyword search, filters, sorting, and pagination.
- Provide a clear, responsive interface and predictable API behavior.
- Demonstrate maintainable, testable software across the frontend, BFF, backend, and database.
- Make local development and full-stack demonstrations reproducible, including Docker-free mock modes.
- Treat future AI-generated game metadata as a proposal for user review and confirmation, not as authoritative data.

## Guiding principles and non-goals

- Keep responsibilities clear between the frontend, BFF, backend API, and database.
- Favor accessible, responsive UI, validated inputs, consistent error handling, and automated verification.
- Keep AI-assisted metadata suggestions optional and subject to user review before saving.
- The documented Docker environment is for local development and demonstration, not a production deployment configuration.
- The project is a portfolio demonstration as well as a collection tool; it does not claim to serve a multi-user production service.
